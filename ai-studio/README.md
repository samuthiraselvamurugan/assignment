# Samuthira Selvamurugan P: Portfolio

Cinematic scroll-driven portfolio (GSAP + ScrollTrigger, three.js, Lenis, Lucide).

    npm install
    npm run dev      # http://localhost:3000
    npm run build    # static site in dist/

All personal content (name, projects, certificates, links) is in the CONFIG object at the top of src/main.js.
Certificate images are in public/certs/.
